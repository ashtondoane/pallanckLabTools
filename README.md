This repository is the container for a website created for the 2024 UW Genomics Summer REU. This website is hosted at https://pallancklabtools.onrender.com/

## Purpose
Automate the data collection and analysis of climbing assays via a webtool which is capable of processing images of test results.

## Outcome
The website successfully sped up the process of data collection and analysis by over 800%, and gave statistically equivalent results as when manually completed. A poster representing these findings is shown below.
